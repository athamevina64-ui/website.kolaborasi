Jawaban LKPD Matematika SPLDV

Penyelesaian Soal SPLDV

1. Menentukan Variabel

Misalkan:
x = Harga dari 1 tempat sampah otomatis
y = Harga dari 1 kipas angin mini

2. Membuat Model Matematika

Paket 1:

6x + 5y = 1.815

Paket 2:

4x + 7y = 1.485

3. Menentukan Harga Masing-Masing Produk

Metode Eliminasi:

6x + 5y = 1.815 | × 7
4x + 7y = 1.485 | × 5

42x + 35y = 12.705
20x + 35y = 7.425
------------------------ -
22x = 5.280
x = 5.280 / 22
x = 240.000

Mencari nilai y:

6x + 5y = 1.815
6(240) + 5y = 1.815
1.440 + 5y = 1.815
5y = 1.815 - 1.440
5y = 375.000
y = 375.000 / 5
y = 75.000

Jadi, hasilnya adalah:

  • Harga barang pertama (x) = Rp 240.000
  • Harga barang kedua (y) = Rp 75.000

4. Kesimpulan

SPLDV dapat digunakan untuk menentukan harga masing-masing barang berdasarkan dua paket penjualan yang memiliki jumlah barang dan harga berbeda. Dengan menggunakan metode eliminasi dan substitusi, diperoleh harga barang pertama sebesar Rp 240.000 dan harga barang kedua sebesar Rp75.000.
