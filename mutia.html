Jawaban LKPD Matematika SPLDV

Menentukan Harga Satuan Produk dengan SPLTV


1. Menentukan Variabel

Misalkan:

x = Harga 1 unit Keysound clock
y = Harga 1 unit Reglow tree

2. Membuat Model Matematika

Berdasarkan harga paket pada promo:

Paket A (2 Keysound clock + 4 Reglow tree): 2x + 4y = 560.000
Paket B (4 Keysound clock + 2 Reglow tree): 4x + 2y = 730.000

3. Menentukan Harga Masing-Masing Produk

A. Metode Eliminasi (Mencari nilai y):

2x + 4y = 560.000 | × 2 ⇒ 4x + 8y = 1.120.000
4x + 2y = 730.000 | × 1 ⇒ 4x + 2y = 730.000
----------------------------------------------- -
6y = 390.000
y = 390.000 / 6
y = 65.000

B. Metode Substitusi (Mencari nilai x):

Substitusikan nilai y = 65.000 ke dalam persamaan Paket A:

2x + 4y = 560.000
2x + 4(65.000) = 560.000
2x + 260.000 = 560.000
2x = 560.000 - 260.000
2x = 300.000
x = 300.000 / 2
x = 150.000

Hasil Perhitungan:

  • Harga 1 unit Keysound clock (x) = Rp150.000
  • Harga 1 unit Reglow tree (y) = Rp65.000

4. Kesimpulan

Sistem Persamaan Linear Dua Variabel (SPLDV) berhasil digunakan untuk menemukan harga satuan dari barang yang dijual secara paket. Dengan metode gabungan eliminasi dan substitusi, didapatkan bahwa harga 1 unit Keysound clock adalah Rp150.000 dan harga 1 unit Reglow tree adalah Rp65.000.
